# 22. `sadno/vle:2.2` 验证记录

日期：2026-08-19。

## 当前范围

本轮只发布2.2后端与 Docker镜像。没有修改父项目，没有提交 `panel-overlay/`，没有修改数据库 schema，也没有使用生产域名、证书或凭据。

## 已完成

- 固定 Docker Official Image `caddy:2.11.4-alpine` 及摘要；
- Caddyfile由官方 Caddy 2.11.4 `adapt` 实际解析；
- 解析结果确认 HTTPS监听 `127.0.0.1:9443`，HTTP-01入口监听 `0.0.0.0:8080`；
- Go单元和集成测试覆盖新节点格式、旧 target兼容、Caddy目录权限、配置生成、站点保留、符号链接拒绝、子进程停止和生命周期合同；
- 新节点 Xray配置固定 target为 `127.0.0.1:9443`；
- `go test -count=1 -mod=vendor ./...`、`go test -race -count=1 -mod=vendor ./...` 和 `go vet -mod=vendor ./...` 均通过；
- linux/amd64镜像内版本为 `vlesshappy 2.2.0` 和 `caddy v2.11.4`；
- 镜像以 UID/GID `65532:65532` 运行，验证通过只读根文件系统、删除全部 capabilities和 `no-new-privileges` 启动；
- 临时 MySQL 8.4完成 `setup`、节点读取、密钥对应关系、运行配置和权限验证；
- 实际生成的 Caddyfile在最终镜像内成功解析，Caddy子进程成功启动并监听预期地址；
- 为避免使用不属于本项目的域名发起公网签发，隔离测试网络故意禁止 ACME外联；Caddy在证书未就绪时没有提前启动 Xray；
- 全部临时测试容器、网络和数据卷已清理。

## 发布门禁

- 提交差异范围已经逐项检查，`panel-overlay/`、`.DS_Store`、线上合并目录和压缩包均未暂存；
- Gitleaks检查暂存差异未发现泄漏；最终暂存快照和完整 Git历史只命中同一个既有公开单元测试夹具：字符串 `password` 及其确定性 UUID期望值，不是凭据；
- 最终镜像环境与构建历史未包含运行时参数或秘密；导出的根文件系统以及 VLE/Caddy二进制可打印字符串均未发现泄漏；
- 只推送审核后的后端提交和 `sadno/vle:2.2` linux/amd64镜像；
- Git提交、PR地址和 Docker Hub远端摘要记录在发布报告中。

真实公网 ACME签发必须由管理员提供已解析域名并开放或透传 TCP/80，不能在使用 `example.com` 的离线验收中伪造为已完成。
