# 08. 实施计划

本文保留确认后的实施顺序。0.2.0-rc.1 已完成阶段 0 至 7 的源码与工具准备；按项目负责人要求，本轮未执行阶段门禁、客户端矩阵、72 小时或 7 天验收。当前执行入口以 `docs/10`、`docs/13` 和 `docs/14` 为准。

## 阶段 0：冻结上游与测试夹具

交付：

- 固定 Go toolchain 和 Xray-core commit/tag；
- 记录上游许可证、来源和最小 patch 策略；
- 从父项目生成 UUID、用户过滤、流量倍率和节点配置固定夹具；
- 建立 `go.mod`、基础 CI、本地测试入口。

门禁：依赖可重复获取，UUID 与 PHP 完全一致，未修改父目录。

## 阶段 1：配置、生命周期和空数据面

交付：

- 严格配置解析与 `validate`；
- secret 文件权限检查；
- 状态目录锁和生命周期状态机；
- 固定 Xray VLESS RAW/REALITY/Vision 入站启动；
- 健康检查和优雅停止骨架。

门禁：无数据库时不监听；错误 secret、target 或端口 fail-closed；日志无秘密。

## 阶段 2：数据库和授权快照

交付：

- migrations；
- MySQL TLS、timeout、连接池；
- 节点/用户读取；
- UUID 和策略编译器；
- 不可变快照、60 秒刷新、数据库退避和 3600 秒陈旧上限。

门禁：所有用户筛选与父项目一致；单坏用户隔离；节点坏配置拒绝发布。

## 阶段 3：Xray 用户同步与会话钩子

交付：

- 多用户 VLESS 入站；
- 原子 add/remove/update；
- 来源 IP 与 user ID 会话关联；
- TCP/Mux/XUDP 会话撤销；
- 解析后 IP 和端口策略；
- 用户/全局资源限制。

门禁：用户禁用、超额、passwd/策略变化在 65 秒内关闭既有会话；限制无泄漏、无负计数。

## 阶段 4：流量计费与 outbox

交付：

- 用户原始上下行计数；
- 不可变 outbox 文件；
- `vless_traffic_batches` 幂等事务；
- 崩溃重放、磁盘上限、最终停止结算；
- 原始节点带宽和倍率用户计费。

门禁：所有故障注入无丢失、无重复、无部分入账；计费误差小于 1%。

## 阶段 5：活跃 IP、设备限制与遥测

交付：

- alive IP 去重和报告；
- online、node info、heartbeat；
- disconnect IP 和设备数限制；
- 结构化日志和运行指标；
- 故障/容量告警状态。

门禁：真实用户数与会话/流量批次解耦；遥测故障不影响可靠计费。

## 阶段 6：面板 overlay 与订阅

所有文件仍留在 `vlesshappy/panel-overlay/`：

- VLESS 服务类和配置解析；
- `?vless=1` 独立 Base64 订阅；
- Mihomo/Clash 聚合；
- 第一方 `links`、`mihomo` 和 capabilities；
- 用户中心按钮和管理员节点表单；
- PHP 测试和 overlay 应用清单。

门禁：旧订阅字节级/语义回归通过；无私钥输出；未直接写父项目。

## 阶段 7：容器、集成与客户端矩阵

交付：

- 非特权、只读、digest 固定的最小镜像；
- MySQL/Xray/订阅端到端测试；
- 具体版本客户端矩阵；
- SBOM、许可证、秘密扫描、发布签名；
- 操作和回滚手册。

门禁：P0 客户端 TCP 与 XUDP 全通过，最终镜像不包含 shell/secret，不要求特权权限。

## 阶段 8：72 小时与 7 天验收

按照 `07-test-release-acceptance.md` 执行。72 小时未通过不进入 7 天；7 天期间发生资源单调增长、计费差异、丢批次或会话撤销失败时，修复后重新计时。

## 提交策略

后续实现应保持小而可审阅的提交：

1. 文档/工具链；
2. 配置与生命周期；
3. 数据库与快照；
4. Xray 用户同步；
5. 会话和策略；
6. 计费/outbox；
7. 遥测；
8. panel overlay/订阅；
9. 容器与发布。

每一提交都必须只包含 `vlesshappy/` 内路径。若某阶段发现必须修改父项目，停止实施，给出目标文件、原因、冲突分析和最小变更清单，等待新授权。

## 完成定义

“能连接”不等于完成。只有代码、自动测试、真实客户端矩阵、exactly-once 计费、故障恢复、72h/7d 报告、安全材料、overlay 和运维手册全部达到文档门禁，才可称为 VLESS REALITY 后端完成。
