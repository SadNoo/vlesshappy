# 06. 安全与威胁模型

## 1. 保护资产

- REALITY 私钥；
- MySQL 凭据和数据库传输；
- 用户 UUID、来源 IP、目标和流量记录；
- 授权快照、流量 outbox 和批次一致性；
- 节点资源、文件描述符、内存、CPU 和出口带宽；
- 订阅 token 与生成的 VLESS URI；
- 构建依赖、镜像和发布物供应链。

## 2. 威胁主体

- 未认证的公网扫描者和主动探测者；
- 有效但恶意或已超额的用户；
- 能控制恶意域名/DNS 响应的目标方；
- 能观察或干扰数据库网络的攻击者；
- 获得只读日志、容器镜像或备份的攻击者；
- 错误配置的管理员；
- 被篡改的上游依赖或构建环境。

## 3. 秘密边界

### 3.1 REALITY 私钥

- 通过固定绝对路径读取，例如 `/run/secrets/vlesshappy_reality_private_key`。
- 拒绝符号链接、目录、组/其他用户可读的文件。
- 建议 owner 为运行 UID，权限 `0400` 或 `0600`。
- 不允许命令行参数、环境变量、数据库列或配置 JSON 直接承载私钥。
- 日志、panic、metrics、诊断包和测试快照必须统一脱敏。

### 3.2 数据库密码

- 与 REALITY 私钥分开文件。
- 生产必须支持 MySQL TLS 验证模式和 CA 文件；禁止默认静默降级明文。
- DSN 打印时移除用户名、密码、地址参数中的 secret。

### 3.3 公开材料

REALITY 客户端密码/公钥、short ID、SNI 和公开节点地址会出现在订阅中，不能当作服务端私钥保护，但也不应无必要写入普通日志。

## 4. REALITY target 风险

未认证 REALITY 流量可能被转发到 `target`。生产门禁：

- target 必须显式配置，不提供“任意自动推荐”。
- 部署前验证目标证书、SAN、TLS 版本和 SNI 行为。
- 优先选择与节点同 ASN、稳定且不会把节点变成通用 CDN 转发器的目标。
- 禁止默认使用 Cloudflare 等可造成滥用转发风险的免费 CDN 目标。
- 监控认证失败/fallback 的连接数和字节数。
- 对异常 fallback 可配置随机化的上下载限速，但必须记录这可能形成额外指纹。
- target 变更视为节点安全配置版本变化，需完整验证和滚动重启。

## 5. 输入验证

- 配置文件拒绝未知字段和宽松类型转换。
- host、端口、SNI、target、short ID、UUID、CIDR、端口范围分别使用专用解析器。
- 数据库字符串不能直接拼接到 Xray JSON、日志或 shell。
- 不通过 shell 启动 Xray 或执行数据库命令。
- 整数运算检查负数、溢出、float 倍率的精度和舍入规则。
- 用户策略非法时隔离该用户；节点级安全配置非法时拒绝节点启动/快照发布。

## 6. 网络与进程权限

- 容器内使用非 root UID。
- 进程不需要 `privileged`、`NET_ADMIN`、宿主网络或 Docker socket。
- 容器监听非特权端口，由宿主/编排层映射外部 443。
- 根文件系统只读；只给状态目录和 secret 挂载必要权限。
- 不包含 shell、包管理器、编译器或调试工具的最终镜像。
- 管理/metrics 端点默认仅监听 loopback 或 Unix socket，并要求显式开启。

## 7. 资源滥用防护

- 握手、用户连接、全局连接、XUDP 会话、DNS 并发、目标拨号、队列和 outbox 都有上限。
- 未认证连接使用更短 deadline 和较小缓冲区。
- 限制单连接首包和累计握手字节。
- 目标拨号有超时，禁止无限 goroutine 和无界 channel。
- 高失败率来源可在内存中短时限速，但不能把未认证来源永久写入数据库。
- 限制 fallback 流量，防止成为第三方转发器。

## 8. 日志和隐私

默认禁止记录：

- REALITY 私钥、数据库密码、完整 DSN；
- 完整 VLESS URI、订阅 token、用户 UUID；
- 用户真实邮箱；
- UDP payload、TCP 内容；
- 完整目标 URL/path。

来源 IP、目标 IP/域名和 user ID 属于敏感运营数据：只在必要事件中记录，支持 hash/截断，并定义保留时间。错误堆栈必须经过同一脱敏器。

## 9. 供应链

- 固定 Go toolchain、Xray-core commit、所有 Go modules 和基础镜像 digest。
- 记录 Xray 最小 patch 集和上游来源。
- 保留 `THIRD_PARTY_NOTICES.md` 并遵守 Xray-core MPL-2.0。
- CI 执行依赖许可清单、漏洞扫描、秘密扫描、SBOM 和可复现构建校验。
- 发布物带 SHA-256 和签名；禁止从浮动 `latest` 构建生产版本。

## 10. 安全停止条件

出现下列任一情况不得发布：

- 私钥进入数据库、订阅、日志或镜像层；
- 无法按用户关闭既有会话；
- 解析后 IP 能绕过 forbidden IP；
- outbox 损坏会被自动丢弃；
- 重放可能造成重复计费；
- 数据库 TLS 配置声称验证但实际未验证；
- 未认证流量可无限使用 target 转发；
- 最终镜像需要特权权限。
