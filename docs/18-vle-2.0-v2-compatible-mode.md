# 18. `sadno/vle:2.0` V2 兼容模式交付

日期：2026-08-19。

## 核心变化

2.0 保留 VLESS REALITY 数据面和安全控制，把数据库合同改为现有 V2 后端模式：

- `sort=15` 仍是独立 VLESS REALITY 节点；
- 公开节点参数直接编码在 `ss_node.server`；
- 流量直接事务写入现有 SSPanel 表；
- 删除专用配置表、批次表、本地 outbox 和 1.0 migration；
- 接受数据库异常时少量漏记或重复，不影响正常协议转发；
- REALITY 私钥仍只从节点本地 secret 文件读取。

## 节点参数

管理员填写：

| 参数 | 含义 |
|---|---|
| `vless_public_host` | 客户端连接地址 |
| `vless_public_port` | 客户端连接端口 |
| `vless_server_name` | REALITY SNI |
| `vless_target` | REALITY 伪装目标 `host:port` |
| `vless_reality_public_key` | 32 字节无填充 Base64URL 公钥 |
| `vless_short_id` | 最多 16 位偶数长度十六进制，可空 |
| `vless_min_client_version` | 可空，只允许数字和点 |

面板保存为：

```text
public-host;public-port;0;tcp;reality;sni=...|pbk=...|sid=...|target=...|minver=...
```

固定值：`tcp`、`reality`、`chrome`、`xtls-rprx-vision`、`raw`、`xudp`。完整 `ss_node.server` 最多 255 字节。

## 订阅语义

| 入口 | VLESS 行为 |
|---|---|
| `?vless=1` | 仅 VLESS REALITY，Base64 行订阅 |
| `?clash=1` | 显式混合配置中加入 Mihomo VLESS |
| `?sing-box=1` | 显式混合配置中加入 sing-box VLESS |
| 第一方 `format=links` | 加入标准 VLESS URI |
| 第一方 `format=mihomo` | 加入 Mihomo VLESS 节点 |
| `?ss2022=1` | 不加入 VLESS |
| `?mu=2` | 保持 VMess-only |
| `?mu=4` | 保持原语义，不由 VLESS overlay 注入 |
| Surge/Loon/SSR/SSD | 不加入 VLESS |
