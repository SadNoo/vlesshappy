## Docker 端到端

使用隔离的临时 Docker 网络、命名卷和 MySQL 8.4，执行了完整的真实交互流程：

1. linux/amd64 镜像在 arm64 Docker Desktop 上通过模拟启动；
2. `setup` 以 TTY 隐藏读取两次无效测试密码，终端输出未回显；
3. 向导生成临时 REALITY 密钥和 16 位 short ID；
4. 将公开测试材料写入临时 `sort=15`、`type=1` 节点；
5. 数据库、用户快照、面板六项公开字段和 REALITY 公私钥配对通过；
6. `/data/runtime` 原子生成；
7. 默认 CMD 启动成功，Xray 和 `vlesshappy` 进入 serving；
8. 容器用户为 `65532:65532`，根文件系统只读；
9. 再次运行 setup 明确拒绝覆盖；
10. 测试容器、网络和命名卷均已清理。
