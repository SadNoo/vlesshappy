# 07. 测试、发布与验收

## 1. 自动化基础门禁

每次提交至少执行：

- `gofmt`/格式检查；
- `go test ./...`；
- `go test -race ./...`；
- `go vet ./...`；
- 固定版本的静态分析和漏洞扫描；
- `ss_node.server` 的 Go/PHP 交叉解析和“无迁移”检查；
- 配置 schema、秘密扫描、依赖许可和容器检查；
- 父项目 overlay 的 PHP 语法和目标测试，但不自动应用到父项目。

## 2. 单元测试

### 2.1 身份与配置

- PHP/Go UUIDv3 固定向量；
- IPv4、IPv6、IPv4-mapped IPv6；
- short ID 长度、奇偶、非 hex；
- host、IDN、IPv6 bracket、端口边界；
- 未知/重复配置字段；
- secret 权限、符号链接和路径类型；
- 日志脱敏，包括 panic/error wrapping。

### 2.2 用户策略

- enable、到期、额度、class/group/admin；
- forbidden IP、CIDR、端口和范围；
- 域名解析后命中禁止 IP；
- disconnect IP 和来源归一化；
- 用户/节点连接限制；
- 单个非法用户隔离；
- 节点配置非法导致快照拒绝。

### 2.3 计费

- 上下行方向；
- 原始流量和倍率流量；
- 小数倍率的固定舍入规则；
- 事务失败后进程内计数恢复；
- 64 位边界和溢出；
- Mux/XUDP 归属不串用户。

## 3. Xray/协议集成测试

必须使用真实固定版本 Xray 实现，不接受 mock 代替以下测试：

- 正确 UUID 可连接，错误/旧 UUID 失败；
- REALITY key、SNI、short ID、fingerprint 组合；
- Vision TCP 双向大流量和半关闭；
- XUDP DNS、普通 UDP echo、IPv4/IPv6；
- UDP payload 至少覆盖 1、64、512、1200 字节；
- Mux 下多个 TCP/UDP 子流；
- 用户删除、禁用、超额、passwd 变化后既有会话关闭；
- forbidden domain 最终解析 IP 拦截；
- 握手、每用户和全局限制；
- 监听失败和配置 reload 回滚。

## 4. MySQL 集成测试

使用与生产兼容的真实 MySQL 容器：

- 第一份授权快照；
- 用户和节点条件过滤；
- 完整流量事务；
- 事务中点故障整体回滚；
- 数据库重启、网络中断、只读、锁等待、死锁；
- 连接池和 timeout；
- MySQL TLS 验证成功和证书错误失败；
- `alive_ip`、online、info、heartbeat 不干扰计费事务。

## 5. 故障注入

- 流量事务执行中断时整体回滚；
- 数据库提交响应丢失时记录可能的重复计费；
- 数据库断开 5 分钟、超过 3600 秒；
- SIGTERM 正常 drain、120 秒强制取消、SIGKILL 恢复；
- 授权 diff 应用到一半失败并回滚；
- 时钟前后跳，授权年龄使用单调时钟保护。

## 6. 订阅测试

- `?vless=1` 精确分支和旧参数不受影响；
- 标准 Base64 解码、末尾换行、稳定排序；
- URI query/fragment 编码、中文节点名、IPv6；
- 用户禁用/到期/超额；
- class/group/bandwidth 过滤；
- 单节点非法被跳过、全无节点返回空；
- 私钥、DSN、内部地址不出现在输出中；
- `?mu=2` 保持 VMess-only；
- `?mu=2`、`?mu=4` 均不加入 VLESS；第一方混合 `links`、`mihomo` 聚合包含 VLESS 且其他协议不变。

## 8. 性能与长稳

### 8.1 72 小时预验收

- 持续混合 TCP、DNS UDP、1200 字节 UDP、Mux；
- 周期性用户新增、删除、禁用和策略变化；
- 周期性数据库短断、恢复和一次容器重启；
- CPU 目标低于分配核的 60%～70%；
- RSS、heap、goroutine、FD 无单调增长；
- FD 使用低于进程上限 50%；
- TCP 建连/传输失败率小于 0.1%；
- 1200 字节 UDP 丢包率在健康网络下小于 0.1%；
- 数据库健康时面板计费与独立流量基准误差小于 1%；
- 故障与重启窗口单独记录漏记/重复量，不把 V2 模式已接受的少量误差误报为协议故障。

### 8.2 7 天生产候选

72 小时全部通过后进行 7 天长稳，包含真实外部 TCP/UDP 探针、滚动重启、数据库维护窗口和一次完整回滚演练。任一资源持续增长或计费不一致都重置观察窗口。

## 9. 发布物

- 固定版本静态 Linux/amd64 二进制；
- digest 固定的非特权最小镜像；
- 配置 schema 和示例，但无任何真实 secret；
- 明确的“2.0 无数据库迁移”说明；
- panel overlay；
- SBOM、第三方许可证、SHA-256 和签名；
- 升级、回滚、密钥轮换和数据库故障手册；
- 客户端矩阵和 72h/7d 报告。

## 10. 上线否决条件

以下任一未通过即不得上线：会话撤销、TCP、XUDP、事务无部分入账、最终解析 IP 策略、秘密扫描、真实客户端矩阵、72 小时预验收。
